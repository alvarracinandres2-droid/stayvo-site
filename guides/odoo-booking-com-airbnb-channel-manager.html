How to connect Odoo with Booking.com, Airbnb and Expedia

Odoo does not ship a channel manager: there is no official connector for Booking.com, Airbnb or Expedia. The reliable way is to put a channel manager in the middle (we use Beds24, which is certified with all the big channels) and sync Odoo with it.

What has to sync, and in which direction

  • Into Odoo: new bookings, date changes, cancellations and blocks from every channel.
  • Out of Odoo: bookings made at the front desk, rooms closed for maintenance, and rates.
  • Never lost: if a channel sells a room that is already taken, the booking must still enter Odoo and warn you. Refusing it means losing a real guest.

Step by step with Stayvo

  1. Install the free Small Hotel PMS and create your room types and rooms.
  2. Install the Beds24 Channel Manager add-on.
  3. In Beds24, create an invite code and paste it in Odoo. Import the structure: room types and units are matched.
  4. Turn on, one by one: receive bookings, send reservations and closures, send rates. Everything starts off.
  5. Optional: paste the webhook URL in Beds24 so bookings arrive instantly instead of every few minutes.
Odoo Online? Odoo Online cannot install third-party modules. You need Odoo.sh or your own server (Community or Enterprise).

Only one or two listings?

If you rent a single house, the iCal Sync add-on imports the Airbnb, Booking.com and Vrbo calendars without a channel manager. It is simpler, but iCal only blocks dates: it does not send rates.
